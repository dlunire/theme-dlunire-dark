# DLUnire Dark Theme

**DLUnire Dark** es un tema de interfaz y resaltado de sintaxis diseñado para **Visual Studio Code** y **Zed Editor**, enfocado en brindar un **alto contraste extremo** con una paleta vibrante sobre un fondo ultraoscuro (`#010305`).

Desarrollado para optimizar la legibilidad en extensas jornadas de programación y reducir la fatiga visual.
